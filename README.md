# Career-event-planner - Campus Career Console 🎓🚀

A modern, high-density academic placement and career development dashboard designed for scheduling, filtering, and organizing institutional career drives, mock interviews, and corporate seminars. Built with pure semantic HTML5, responsive CSS grid/flex layout architecture, and modular ES6+ JavaScript.

## 🚀 Key Academic Features Implemented

- **Dynamic Data Transformation Pipeline:** Advanced JavaScript array operations (`.filter()` and `.sort()`) process search queries, placement categories (Technical/Cultural/Sports/Corporate), and chronological date adjustments instantly without page reloads.
- **Robust Student Validation Engine:** Registration forms are verified through strict Regular Expression configurations (validating institutional email formats and alphanumeric college roll number bounds) with live red/green alert indicators.
- **Persistent State Sandbox Architecture:** A synchronization engine connects running object arrays directly into the browser's native `localStorage` sandbox API, keeping data intact even after refreshing the tab.
- **Premium Corporate UI Strategy:** Replaced standard legaly sidebars with modern placement KPI metric counters, tabbed category filters, layout view toggles (Grid Matrix vs. High-Density Table), and decoupled asset overlay modals.

## 📂 Project Architecture

```text
├── index.html   # Semantic UI layouts & modal registration blocks
├── style.css    # Clean modern SaaS-lite colors & placement variables
└── app.js       # Pure ES6 student state management & processing pipeline
```

## 🛠️ Tech Stack Competencies Demonstrated

- **Core UI Layers:** HTML5 (Semantic Structure), CSS3 (Custom Variables, Flexbox, Grid)
- **Functional Logic:** JavaScript ES6+ (Native Array Pipelines, Localized Date Parsing, Form Guard Validations)
- **Memory Management:** HTML5 Web Storage API (`localStorage`)
- **UX Best Practices:** Responsive Fluid Typographies, Category Badges, State Caching Summary
